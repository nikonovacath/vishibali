# Вышибалы

В простонародье «Чапаев»: шашки на шахматной доске, которые выбивают друг друга щелчком.

У каждого 8 шашек на своём первом ряду. Зажимаешь свою шашку и тянешь назад, это сила удара. Стрелка качается туда-сюда, и шашка летит туда, куда она смотрит в момент, когда отпускаешь. Выбил чужую, а твоя осталась на доске, бьёшь ещё раз. Раунд выигрывает тот, у кого остались шашки, и в следующем раунде встаёт на ряд ближе. Когда ряды сомкнулись, победитель толкает проигравшего назад, и кого вытолкнули за край, тот проиграл.

Можно играть с ботом (лёгкий, средний, «Дед») или с другом по ссылке, с чатом.

Вся игра в одном файле `index.html`. Онлайн работает через Firebase (тот же проект, что у «Уголков»), правила базы лежат в `database.rules.json`.
